Техническое задание для AI-агента: Написание регрессионных тестов (Characterization Tests) для бэкенда

Цель: Покрыть существующую бизнес-логику FastAPI-приложения интеграционными тестами с помощью pytest до начала рефакторинга, зафиксировав текущее поведение системы (включая известные дефекты).

Требования к окружению и стеку:

    Разместить тесты в директории backend/tests/.

    Использовать pytest, pytest-asyncio и httpx.AsyncClient для тестирования эндпоинтов в асинхронном режиме.

    Обеспечить возможность запуска тестов внутри запущенного Docker-контейнера (docker exec -it backend pytest).

Обязательные тест-кейсы для реализации:

    Интеграционный сценарий загрузки: Отправка POST-запроса на /files с тестовым текстовым файлом, проверка статуса 201 Created и начального статуса обработки uploaded.

    Проверка логики сканирования угроз: Верификация работы модуля сканирования для файлов с безопасными (.txt) и потенциально опасными (.exe) расширениями.

    Корректность извлечения метаданных: Проверка генерации metadata_json (подсчет строк и символов для текстовых файлов).

    Генерация алертов: Запрос к эндпоинту /alerts и проверка появления соответствующего уведомления после завершения обработки файла.

    Целостность скачивания: Проверка того, что эндпоинт GET /files/{id}/download возвращает байты, идентичные исходному загруженному файлу.

    Регрессионный тест удаления (Expected Failure): Фиксация в коде теста текущей ошибки 500 Internal Server Error при вызове DELETE /files/{id}, чтобы использовать этот тест как индикатор успешного исправления бага с каскадным удалением в будущем.
