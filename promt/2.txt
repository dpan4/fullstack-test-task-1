> **Задача:** Провести рефакторинг бэкенда FastAPI для исправления упавших интеграционных тестов.
> **План работ:**
> 1. **Исправление каскадного удаления (`src/models.py`):**
> * Добавить `cascade="all, delete-orphan"` к связи между `StoredFile` и `Alert`.
> * Добавить обработку удаления физического файла с диска при вызове `DELETE /files/{id}` в `src/service.py`.
> 
> 
> 2. **Исправление вызова фоновых задач (`src/service.py`):**
> * В методе создания файла запустить задачу Celery (`scan_file_for_threats.delay(file_id)`).
> 
> 
> 3. **Рефакторинг Celery и Event Loop (`src/tasks.py`):**
> * Удалить костыль `run_in_worker_loop` и ручное создание `asyncio.new_event_loop()`.
> * Перевести асинхронную работу с БД в Celery на корректный изолированный сеанс SQLAlchemy (`async_sessionmaker` или синхронный Engine для Celery-воркеров), чтобы исключить ошибку `sqlalchemy.exc.InterfaceError`.
> 
> 
> 4. **Критерий приемки:**
> * Команда `uv run pytest --cov=src` должна показать 0 ошибок (`0 failed, 0 errors`) и прохождение всех тестов, включая ранее падающий тест на удаление.
